# Food Image Upload API Documentation

## Overview

The Food Image Upload API allows users to upload food images for AI-powered analysis using the Z-AI platform. This is a **public endpoint** that does not require authentication.

## Endpoints

### 1. Upload Food Image (Standard)

**Endpoint:** `POST /api/v1/food-images/upload`

**Authentication:** None required (public endpoint)

**Description:** Upload a food image for analysis. The API validates the image, converts it to JPEG or PNG format, and sends it to Z-AI for food analysis.

#### Request

**Content-Type:** `multipart/form-data`

**Parameters:**
- `file` (required): The image file to upload
  - **Supported formats:** JPEG, PNG, GIF, BMP, WebP
  - **Max size:** 10MB
- `target_format` (optional): Target conversion format
  - **Values:** `JPEG` (default) or `PNG`
  - **Default:** `JPEG`

**Example using cURL:**
```bash
curl -X POST "http://localhost:8000/api/v1/food-images/upload" \
  -F "file=@/path/to/food-image.jpg" \
  -F "target_format=JPEG"
```

**Example using Python requests:**
```python
import requests

url = "http://localhost:8000/api/v1/food-images/upload"
files = {"file": open("food-image.jpg", "rb")}
data = {"target_format": "JPEG"}

response = requests.post(url, files=files, data=data)
print(response.json())
```

**Example using JavaScript (fetch):**
```javascript
const formData = new FormData();
formData.append('file', fileInput.files[0]);
formData.append('target_format', 'JPEG');

const response = await fetch('http://localhost:8000/api/v1/food-images/upload', {
  method: 'POST',
  body: formData
});

const result = await response.json();
console.log(result);
```

```json

  "detail": "File size exceeds maximum allowed size of 10MB"
```

```json

  "success": false,
  "message": "Internal server error",
  "detail": "Failed to analyze image with Z-AI: Connection timeout"
}
```

### 2. Upload Food Image (Streaming)

**Endpoint:** `POST /api/v1/food-images/upload/stream`

**Authentication:** None required (public endpoint)

**Description:** Upload a food image and receive streaming analysis results. This provides real-time analysis as it's being generated by the AI.

#### Request

Same as standard upload endpoint.

#### Response

**Content-Type:** `text/event-stream`

**Server-Sent Events (SSE) Format:**

```
data: {"type": "image_info", "data": {"original_filename": "food.jpg", ...}}

data: {"type": "analysis_chunk", "data": "This is a plate"}

data: {"type": "analysis_chunk", "data": " of Pad Thai"}

data: {"type": "analysis_chunk", "data": ", a popular Thai"}

data: {"type": "complete"}
```

**Example using JavaScript (EventSource):**
```javascript
const formData = new FormData();
formData.append('file', fileInput.files[0]);

const response = await fetch('http://localhost:8000/api/v1/food-images/upload/stream', {
  method: 'POST',
  body: formData
});

const reader = response.body.getReader();
const decoder = new TextDecoder();

while (true) {
  const { done, value } = await reader.read();
  if (done) break;

  const chunk = decoder.decode(value);
  const lines = chunk.split('\n');

  for (const line of lines) {
    if (line.startsWith('data: ')) {
      const data = JSON.parse(line.slice(6));

      if (data.type === 'image_info') {
        console.log('Image info:', data.data);
      } else if (data.type === 'analysis_chunk') {
        console.log('Analysis chunk:', data.data);
      } else if (data.type === 'complete') {
        console.log('Analysis complete');
      }
    }
  }
}
```

## Image Processing Pipeline

1. **Validation**
   - Check file size (max 10MB)
   - Verify file extension (jpg, jpeg, png, gif, bmp, webp)
   - Validate image format by opening and verifying

2. **Conversion**
   - Convert to JPEG or PNG format as specified
   - For JPEG: Convert RGBA to RGB with white background
   - For PNG: Preserve transparency

3. **Z-AI Upload**
   - Convert image to base64
   - Create data URL with proper MIME type
   - Send to Z-AI vision model (glm-4v)
   - Receive food analysis

4. **Response**
   - Return comprehensive analysis
   - Include image metadata
   - Provide Z-AI usage statistics

## Error Handling

### Common Errors

| Error Code | Cause | Solution |
|------------|-------|----------|
| 400 | Invalid file extension | Use supported formats (JPEG, PNG, GIF, BMP, WebP) |
| 400 | File too large | Reduce file size to under 10MB |
| 400 | Invalid image content | Ensure file is a valid image |
| 400 | Invalid target format | Use 'JPEG' or 'PNG' only |
| 500 | Z-AI connection error | Check Z-AI API key and network connection |
| 500 | Image processing error | Check image is not corrupted |

## Configuration

Required environment variables in `.env` file:

```env

ZAI_API_KEY=your-zai-api-key-here
ZAI_BASE_URL=https://api.z.ai/api/paas/v4/
```

### Getting Z-AI API Key

1. Visit [Z.AI Platform](https://z.ai)
2. Create an account or sign in
3. Navigate to API Keys section
4. Generate a new API key
5. Copy the key to your `.env` file

## Usage Limits

- **Max file size:** 10MB per upload
- **Supported formats:** JPEG, PNG, GIF, BMP, WebP
- **Output formats:** JPEG or PNG only
- **Rate limits:** Depends on your Z-AI plan
- **Token usage:** Billed per Z-AI API usage

## Best Practices

1. **Image Quality**
   - Use high-quality images for better analysis
   - Ensure good lighting and clear visibility of food
   - Avoid blurry or low-resolution images

2. **File Size**
   - Compress images before upload to save bandwidth
   - Recommended size: 500KB - 2MB for optimal balance
   - Use appropriate resolution (1024x768 or higher)

3. **Error Handling**
   - Always check the `success` field in response
   - Handle validation errors gracefully
   - Implement retry logic for network errors

4. **Performance**
   - Use streaming endpoint for better UX on slow connections
   - Consider caching results to reduce API calls
   - Implement client-side image validation before upload

## Security Considerations

1. **File Validation**
   - All uploads are validated for file type and size
   - Image content is verified by PIL library
   - Invalid files are rejected with detailed error messages

2. **Rate Limiting**
   - Consider implementing rate limiting in production
   - Prevents abuse of the public endpoint
   - Protects against DDoS attacks

3. **Content Security**
   - Uploaded images are not stored on server
   - Images are processed and sent to Z-AI immediately
   - No persistent storage of user data

4. **API Key Security**
   - Z-AI API key is stored securely in environment variables
   - Never expose API keys in client-side code
   - Rotate keys regularly for security
