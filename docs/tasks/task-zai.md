# Api tích hợp z-ai
Hãy tạo một đầu api không cần xác thực cho người dùng upload hình ảnh.
Mục đích sử dụng: user chụp ảnh món ăn và upload lên api này. 
Logic xử lý:
- Đầu tiên phải kiểm tra file upload có phải là hình ảnh hay không
- Phải chuyển ảnh đó về dạng file jpg hoặc png để xử lý với thư viện z-ai
Github url: https://github.com/zai-org/z-ai-sdk-python
Latest version: v0.0.4.2
